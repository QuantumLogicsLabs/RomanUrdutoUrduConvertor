# ============================================================================
#  Roman Urdu -> Urdu spelling-variant dictionary
#
#  Format:   اردو = variant1, variant2, variant3 ...
#  * One Urdu word (or short phrase) per line, followed by every common
#    Roman spelling people use for it (kya, kia, kiya ...).
#  * A variant may contain spaces -> it becomes a phrase that is matched
#    across words (used to resolve ambiguity, e.g. "keh raha" vs "keh").
#  * If the same Roman spelling appears twice, the FIRST line wins.
#  * Put your own words in custom_words.txt (project root) - they override
#    this file and you never have to touch this one.
# ============================================================================
